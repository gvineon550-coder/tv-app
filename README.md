# 📺 TV

Клиент для просмотра прямых эфиров на **Android TV** и **Android**.

---

## ✨ Возможности

- 📡 Список каналов с группами и поиском
- 📅 Программа передач с подсветкой текущей
- ▶️ Воспроизведение HLS-потоков (ExoPlayer)
- 🎚 Выбор качества (ограничение по высоте кадра)
- 🌐 Поддержка HTTP-прокси для API
- 🚫 Скрытие недоступных каналов
- 💾 Кеш списка каналов и настроек

---

## 📦 Установка

1. Открой раздел **Releases** в этом репозитории.
2. Скачай последний `app-debug.apk`.
3. Разреши установку из неизвестных источников на устройстве.
4. Установи APK.

---

## 🛠 Сборка

Проект собирается автоматически через **GitHub Actions** при каждом
коммите в `main`. Свежий APK появляется в разделе **Releases** и в
артефактах workflow.

---

## 🧰 Технологии

- **Kotlin** — язык
- **Jetpack Compose** — интерфейс
- **AndroidX Media3 (ExoPlayer)** — воспроизведение HLS
- **Retrofit + OkHttp** — сеть
- **Hilt** — внедрение зависимостей
- **DataStore** — настройки и кеш

---

## 💡 Источник идеи

Концепция и логика работы с потоками вдохновлены проектом
[rutube-efir](https://github.com/zloi-user/rutube-efir)
(Python + PyQt6, десктоп).
Реализация для Android TV написана с нуля на Kotlin.
