## 📺 О проекте

Лёгкий Android TV клиент для просмотра прямых эфиров **Rutube**.

- **Размер APK:** ~3 МБ
- **RAM при игре:** 150–250 МБ
- **CPU:** 5–15% (аппаратное декодирование)
- **Каналов:** ~259 (из них ~136 с прямыми URL)
- **Минимальная версия Android:** 6.0 (API 23)

## ✨ Возможности

- 📺 Список каналов с группами и избранным
- 🎬 HLS-воспроизведение через ExoPlayer (до 1080p)
- 🐞 Диагностический оверлей (кодек, fps, битрейт, буфер)
- ⏱ Таймер сна (до 12 часов)
- 📱 Управление пультом Android TV
- 🔒 PIN-защита настроек
- 🆔 Лицензирование по ID устройства
- 🌐 Опциональный HTTP-прокси

## 🏗️ Архитектура

[GitHub Actions] ──раз в неделю──> Rutube API
│
▼ парсит каналы → channels.json
│
[GitHub Pages] ──> channels.json + licenses.json
│
[Приложение] ──читает JSON──> играет каналы


Парсинг каналов выполняется **на серверах GitHub** — IP пользователя
не используется для запросов к Rutube API.

## 🛠️ Стек

- Kotlin 2.0.21
- Jetpack Compose + TV Material 3
- ExoPlayer (Media3 1.5.1)
- Hilt, Retrofit, OkHttp, Coil, DataStore
- Python 3.11 (парсер)
- GitHub Actions (CI)

## 📦 Сборка

APK собирается автоматически через GitHub Actions при push в `main`.

Ручной запуск:
- **Actions** → **Build APK** → **Run workflow**

Парсер каналов:
- **Actions** → **Parse Rutube Channels** → **Run workflow**

## 📥 Установка

1. Скачай APK из [Releases](https://github.com/gvineon550-coder/tv-app/releases)
2. Установи на Android TV / приставку
3. При первом запуске — ознакомься с дисклеймером и нажми «Я СОГЛАСЕН»
4. Приложение покажет **ID устройства** — попроси владельца активировать

## 🔐 Активация

Приложение защищено привязкой к ID устройства. Для активации:

1. На новом устройстве — приложение покажет **4-значный ID** (например, `4821`)
2. Владелец добавляет ID в `licenses.json` в ветке `gh-pages`
3. Устройство активируется автоматически

## ⚖️ Правовая информация

- Приложение воспроизводит **публично доступные** видеопотоки Rutube
- Не хранит, не копирует, не распространяет видеоконтент
- Все права на контент принадлежат их правообладателям
- Приложение не является официальным клиентом Rutube
